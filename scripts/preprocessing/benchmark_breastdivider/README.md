# BreastDivider benchmark scripts

The scripts that produced `docs/PREPROCESSING_BENCHMARK_BREASTDIVIDER.md`. They carry the dl3/dl0
paths they ran with (`/home/swarm/bd_bench`, `/mnt/swarm_alpha/bd_bench`, `/mnt/dlhd0/bd_bench_duke`)
and expect the unzipped `odelia-preprocessing-0.2.1` package next to them (`bdpp/`) plus a venv with
torchio, SimpleITK and nibabel. See section 7 of the report for what each script does.
